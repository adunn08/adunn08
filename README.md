Technical product manager building AI agent systems, with an SEO and growth background. I maintain [RampStack](https://rampstack.co), open-source skills, tools, and workflows for Claude, and run [OpenAddict](https://openaddict.com), a lab that measures whether AI prompting advice and skill files actually work. Based in Colorado.

Two rules run through everything I ship:

- **Agents do the work, people own the decisions.** My agents open draft PRs. They never merge their own work.
- **Derivation over relay.** Published numbers are computed from source data, not copied from someone else.

I'm looking to collaborate on agent skills, MCP tooling, evals, and SEO/AEO infrastructure. Issues and PRs are welcome on claude-skills and the theme repos.

#### Building

- **[claude-skills](https://github.com/rampstackco/claude-skills)** [![GitHub stars](https://img.shields.io/github/stars/rampstackco/claude-skills?style=flat&color=gold)](https://github.com/rampstackco/claude-skills) - 100+ stack-agnostic Claude Skills for the full web lifecycle: brand, design, content, SEO, product, dev, ops, and growth. Includes an Ahrefs MCP-powered SEO audit suite (the `seo-*` skills). MIT licensed, CI-validated. Listed in [awesome-claude-skills](https://github.com/ComposioHQ/awesome-claude-skills#business--marketing).
- **[Krine](https://github.com/rampstackco/krine), [Tholo](https://github.com/rampstackco/tholo), [Basano](https://github.com/rampstackco/basano)** - Framework docs and worked examples for three engines RampStack operates on the catalog: Krine runs convergent product work (specs, roadmaps, experiment reads) and hands divergent calls to a person; Tholo plans a build and selects only the skills it needs; Basano reviews a finished build and reports what holds and what fails. The engines run at rampstack.co; the repos hold docs, examples, and output schemas.
- **[OpenAddict](https://openaddict.com)** - Control vs. treatment measurement of prompting claims and skill files across Claude, GPT, and Gemini, with published verdicts.
- **[Themes](https://github.com/rampstackco?q=theme)** - Grab-and-go web themes (glassmorphism, neobrutalism, brutalist, corporate memphis) with Tailwind and shadcn tokens, measured contrast, and live demos.

All three engines run on the open claude-skills catalog.

Install the catalog as Claude Code plugins ([marketplace source](https://github.com/rampstackco/plugins)):

```
/plugin marketplace add rampstackco/plugins
/plugin install rampstack-starter@rampstack
```

See it in action: [rampstack.co/showcase](https://rampstack.co/showcase), demonstration sites produced end to end by the engines running on the catalog.
